# Architecture

| Task | Entry points | Contract |
| --- | --- | --- |
| Panel composition and cards | [panel.ts](../src/panel.ts), [note-cards.ts](../src/notes/note-cards.ts), [panel.html](../src/panel.html) | The panel composes host requests and feature modules. The card list owns card DOM, editor lifetimes, drag, focus, deletion and reconciliation. On card focus leaving, delete whitespace-only content without confirmation, not on load, internal control focus, drag, readiness changes, or scope unload. Recheck the latest content in the ordered deletion so queued typing cannot be lost. With default Reading, existing cards open in reading mode and edited cards return to it on focus leaving; new cards start in editing mode. |
| Active worktree | [worker.mjs](../src/worker.mjs), [focus.ts](../src/worktree/focus.ts), [protocol.ts](../src/protocol.ts) | Accept one active target from a complete CLI snapshot. Block editing for ambiguous or truncated results. The bounded CLI development probe must match this worker's nonce. Hide DEV when the result is unknown. |
| Notes and drafts | [session.ts](../src/notes/session.ts), [note-collection.ts](../src/notes/note-collection.ts) | Own exact-scope ordered collections, stable card keys, focus generation guards, full-snapshot drafts and ordered writes. Any card in the ready scope may save; stale scope keys cannot. Legacy strings stay one note and migrate lazily. Single-note deletion is an ordered target-only transaction, not a global lease or refocus. After success, filter the deleted ID from queued snapshots for that draft's lifetime; an explicit lease replacement creates a new draft and may restore the same ID. Invalidate only changed or removed card states after restore or clean-cache refresh; reordering retains history. Global deletion resets all states. An exclusive operation lease for transfer or bulk deletion suspends editing and stale loads, drains writes and pending target deletions, and resumes the latest focus when finished. A finished lease cannot read or write notes. Exclusion applies only within this panel. |
| Source and help | [source-editor.ts](../src/editor/source-editor.ts), [source-state.ts](../src/editor/source-state.ts), [source-commands.ts](../src/editor/source-commands.ts), [source-clipboard.ts](../src/editor/source-clipboard.ts), [source-actions.ts](../src/editor/source-actions.ts), [source-menu.ts](../src/editor/source-menu.ts), [shortcut-help.ts](../src/editor/shortcut-help.ts) | Each card owns one editor and its selection, scroll and undo. Bindings and shortcut descriptions live together; native clipboard events and the menu share exact-source clipboard operations. Guard readiness, key, epoch and revision. Restore rejected read-only or stale candidates synchronously through undo (redo for rejected Undo), without publishing them. No plugin character cap applies. Dispose views and listeners. |
| Settings | [note-preferences.ts](../src/settings/note-preferences.ts), [note-settings-view.ts](../src/settings/note-settings-view.ts) | Preserve independent preferences for Source line numbers, single-note deletion confirmation, default note mode, and HTTP(S) link destination. Confirmation defaults to On; mode defaults to Editing; link destination defaults to the system browser. The model owns initialization separately from value readiness, ordered optimistic writes, last-saved rollback, and same-value retry. Ignore the retired character-limit key without changing its stored value. |
| Transfer | [note-archive.ts](../src/transfer/note-archive.ts), [notes-transfer.ts](../src/transfer/notes-transfer.ts), [note-transfer-view.ts](../src/transfer/note-transfer-view.ts) | The codec validates bounded version 2 collection archives and accepts version 1 text archives losslessly. Transfer owns scope-level replacement, host quota preflight, protection, and partial-write policy through a session lease. IDs and order survive transfer. The view calls `orca.files.saveAs` with an `ArrayBuffer` in a fresh gesture. Handle `saved` and `cancelled` distinctly. There is no download fallback. |
| Preview | [dialog.ts](../src/dialog.ts), [preview.ts](../src/markdown/preview.ts) | Preserve iframe keyboard behavior and HTML sanitization. |
| Link routing | [note-links.ts](../src/markdown/note-links.ts), [note-link-view.ts](../src/markdown/note-link-view.ts), [note-link-routing.ts](../src/worktree/note-link-routing.ts), [worker.mjs](../src/worker.mjs) | Route HTTP(S), including from remote scopes, to the configured external browser or a new Orca browser tab; keep `mailto:` external. Resolve relative files from a local note's worktree root, check the canonical destination is contained, and open it through `editor.open({workspaceId,path})`. Orca's editor API does not guard against filesystem changes between the check and open. Remote file links are unsupported and must be rejected visibly. Reject unsupported protocols, paths outside the worktree, and ambiguous, stale, or wrong-host scopes visibly. Use the trusted worker CLI for browser tabs, not a browser Host API. Preserve exact host/path identities and the `notes.focused` contract. |
| Identity and positions | [protocol.ts](../src/protocol.ts), [source-text.ts](../src/source-text.ts), [markdown-tasks.ts](../src/markdown/markdown-tasks.ts), [markdown-list.ts](../src/markdown/markdown-list.ts) | Keep exact identities in one place. Preserve raw mixed line separators and UTF-16 offsets separately from CodeMirror's canonical LF document. History inverts exact-source effects. |

Preview renders fenced code as escaped plain text regardless of language. DOMPurify sanitizes the rendered Markdown. CodeMirror's Source highlighting is independent. Mermaid uses the ordinary code path.

Preserve Orca's guest resource and asset-session restrictions on remote images, fonts, stylesheets, and network calls.

Source uses explicit light/dark syntax palettes and host surface colors. If the comment color has insufficient contrast against an opaque host canvas, Source uses the host body foreground when it improves contrast. The check runs for same-scheme theme changes too. Transparent canvases retain the syntax palette. This is not a contrast guarantee for every theme or syntax token. Preview uses underlined body-colored links, semantic inline-code fills and borders, and host-colored plain code blocks.

Orca's HTML panel transpiler does not resolve bare npm imports. [build.mjs](../build.mjs) bundles Preview and selected CodeMirror extensions into the panel. Source needs no editor worker, font asset, remote language loading, or all-language catalogue. Generated newlines use the note's initial majority policy; untouched mixed separators stay exact. Clipboard input preserves the plain text supplied by the browser, which may already have been normalized by the OS.
