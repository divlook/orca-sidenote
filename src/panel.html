Back up or restore notes

Notes only, in this plugin store. Settings and undo history are not transferred. Host and path identities stay exact; paths are never file destinations.

First save or copy unsaved content in all other Note panels using this store, then close them. Other panels cannot be detected or locked. This is not a cross-panel transaction.

Backup

Includes all stored notes plus separate recovery drafts from this panel, including failed saves and empty clears. Nothing is shortened.

Restore

Choose a UTF-8 JSON backup (up to 16 MiB). Notes absent from the backup are kept. Choose a collection candidate for each host and path, then preview. Original text and collection order stay intact.

Replacing text requires a saved protection file containing affected stored originals and all local recovery drafts. Changed notes get new undo history; unchanged notes keep it.

Restore stops on the first failed request. Its outcome may be unknown; earlier writes are not rolled back. Preview again before retrying.
